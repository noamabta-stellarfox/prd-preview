Background

Business Motivation

Pre-level boosters give players a strategic boost before a level begins. They are selected in the Level Start popup and inserted into the stockpile at level start, activating when drawn during play.

  • Rewards: pre-boosters are weaker than regular in-level boosters, which makes them a cost-effective reward type. They can be distributed freely as liveops rewards without cannibalizing monetization — players still purchase the stronger in-level boosters when they really need to win.
  • Level Streak: pre-boosters are commonly paired with streak reward systems — they motivate players to never lose an attempt by giving them an edge on harder levels.
  • Monetization: a coin sink that players purchase to improve their chances on hard/super-hard levels. Loss aversion at difficult levels drives booster purchases.
  • Engagement: once players receive an unlimited pre-booster reward, they are motivated to play sessions to “use it up” before the timer expires — creating prolonged engagement.

KPIs

Primary KPIs

  • Pre-booster reward redemption rate — % of players who use a pre-booster received as a reward within 7 days of receiving it.
  • Reward-to-purchase conversion — % of players who, after receiving pre-booster rewards, go on to purchase pre-boosters with coins.
  • FTUE completion rate — % of players who select and use a booster on the FTUE tutorial level.
  • Unlimited reward engagement — Session length change when unlimited pre-boosters are active (measures “use it up” behavior).

Secondary KPIs

  • Per-booster selection rate — Which of SWAP / WILD / PEEK is most selected (inventory vs. coin purchase).
  • Pre-booster purchase rate — % of level attempts where at least one booster is bought with coins (inventory = 0 flow).
  • ARPDAU impact — Incremental revenue from the coin sink, net of cannibalization from in-level boosters.
  • Unlimited timer stacking rate — How often players stack unlimited rewards on an already-active timer.

Detailed Requirements

Pre-boosters are special booster cards added to the stockpile before a level starts. Players select them in the Level Start popup or Level Fail popup before tapping PLAY. Selected boosters are deducted from inventory (or charged in coins) and inserted into the stockpile using the Reward Card Insertion Logic.

General Logic

  1. Pre-level boosters are selected in the Level Start popup (or Level Fail popup) before entering an attempt.
  2. We will develop 3 pre-booster types (SWAP, WILD, PEEK).
  3. The player can select to use up to one pre-booster from each of the available types in each attempt (max 3 active).
  4. He can select it from existing booster inventory or buy a single pre-booster with coins (one click purchase).
  5. Once the player selected a pre-booster(s) and entered an attempt:
        a. The selected pre-booster(s) will be deducted from player inventory (or coins deducted in case the inventory for that booster = 0).
        b. The selected pre-booster(s) will be inserted (animated) into the stockpile at the start of the level.
        c. They follow the Reward Card Insertion Logic (see Core Mechanics PRD).
  6. To activate the pre-booster:
        a. The player draws the pre-booster card from the stockpile.
        b. The booster effect triggers immediately upon drawing.
  7. Pre-Boosters can be gained by:
        a. Reward (from features and live-ops).
        b. Purchase for coins (in Level Start popup).
        c. Offers (in Lobby and Store).
  8. Unlock level:
        a. Each pre-booster will have its own unlock level, set in the Feature Unlock Configuration (see Configuration section).
        b. The pre-booster will appear as locked until reaching the unlock level (in Level Start/Fail Popups).
        c. A tutorial slide will appear on top of the Level Start popup when reaching the unlock level for each pre-booster.
  9. Unlimited Pre-booster:
        a. Each pre-booster will also have an unlimited version, so we can give it as a reward for a specific period of time.
        b. The unlimited versions of all pre-boosters should be available as a reward in all liveops and offers.

Selecting Pre-Boosters

Booster selection happens in the Level Start popup or Level Fail popup. The selection flow is identical for both:

  1. If this booster's inventory >= 1:
        a. The booster shows the current inventory amount for that booster
        b. Clicking its button will replace the number with a checkmark to show it's selected
            i. but it will only be deducted from the inventory and activated once the player actually started the attempt (after clicking the Play button)
            ii. At this stage the player can click again on the booster to deselect it
  2. If this booster's inventory = 0:
        a. Display:
            i. If coins >= price: Shows coin price.
            ii. If coins < price: Shows RV Badge (Current/No Store) OR coin price (Future/With Store).
        b. If player coin inventory >= booster price:
            i. Clicking selects the booster (checkmark).
                1. Coins deducted/activated only on Play.
                2. Click again to deselect.
        c. If player coin inventory < booster price:
            i. Current (RV Flow): Clicking plays Rewarded Video.
                1. On completion: Grants 1 booster + Auto-selects immediately.
            ii. Future (Store Flow): Clicking opens Store popup.
                1. If coins purchased: Auto-selects booster (deducted on Play).
                2. If closed without purchase: Returns to popup, booster NOT selected.

Loading Pre-Boosters In Level

  • Insertion sequence (exact order):
  1. Card entry animation plays (see Level Flows PRD).
  2. Pre-booster insertion animation plays — each selected booster materializes center-screen, flies into stockpile. Cards chain with slight overlap (see Asset List).
  3. First card is auto-drawn from stockpile to waste pile.
  4. Player can now act.
  • Insertion uses the Reward Card Insertion Logic (Core Mechanics PRD):
  • • First booster: inserted 2 cards from top of stockpile.
  • • Subsequent boosters: inserted 2 cards below the deepest existing special card in the pile.
  • Inventory / coins are deducted before the insertion animation begins (on PLAY tap).

Unlimited Pre-Boosters

Mechanics

  • Each pre-booster type has an unlimited version available as a liveops / offer reward.
  • When an unlimited reward is received: timer activates immediately (wall-clock, real-time).
  • Inventory does NOT decrease while unlimited is active — booster is free to use each attempt.
  • Duration stacking: receiving an additional unlimited reward adds its duration to the active timer.
  • All 3 types can be in unlimited mode simultaneously — each has its own independent timer.
  • Once timer expires: booster returns to normal inventory state.

Display

  • Button shows ∞ icon while unlimited is active.
  • Real-time countdown timer shown on the button: hh:mm:ss (wall clock, not session time).

Reward Configuration

  • reward_type: unlimited_swap / unlimited_wild / unlimited_peek
  • reward_value: duration in seconds

Cheats

  • SWAP inventory override: numeric input — sets player SWAP pre-booster count to specified value.
  • WILD inventory override: numeric input — sets player WILD pre-booster count to specified value.
  • PEEK inventory override: numeric input — sets player PEEK pre-booster count to specified value.
  • SWAP unlimited override: sets unlimited SWAP active with specified duration in seconds.
  • WILD unlimited override: sets unlimited WILD active with specified duration in seconds.
  • PEEK unlimited override: sets unlimited PEEK active with specified duration in seconds.
